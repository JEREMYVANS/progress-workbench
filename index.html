云端同步

把数据存到你自己的 GitHub 私有 Gist，手机和电脑自动同步。密钥仅保存在本机浏览器，不会上传到代码。

  1. 打开 github.com → 右上角头像 → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic)
  2. 勾选 gist 权限，生成后复制以 ghp_ 或 github_pat_ 开头的令牌
  3. 粘贴到下方，点击「测试并保存」，会自动建一个仅你可见的私有 Gist 存放数据

发布到 GitHub Pages（永久固定地址）

把本网站发布到你自己的 GitHub 账号，获得永久地址（例如 用户名.github.io/progress-workbench），不再每次变化。需要上方令牌同时勾选 gist 和 repo 权限（生成时两个都勾上即可）。
